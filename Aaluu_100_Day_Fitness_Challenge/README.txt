AALUU'S 100-DAY FITNESS CHALLENGE

Open index.html in a browser to run it.

GITHUB PAGES:
1. Create a public GitHub repository named 100-day-fitness.
2. Upload index.html.
3. Settings -> Pages -> Deploy from branch -> main -> / (root) -> Save.
4. GitHub will give you a public link to send to Aaluu.

The app stores progress in the browser using localStorage.
